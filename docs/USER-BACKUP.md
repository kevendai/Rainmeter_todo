# 用户配置备份与迁移

Todo 设置窗口的“关于”页提供“导出用户配置”和“导入用户配置”。

## 备份范围

默认的配置备份包含：

- CalDAV 地址、账号和密码
- DeepSeek、File Browser 与论文评分设置
- 腾讯云标题翻译凭据
- Todo/Calendar 共用界面缩放
- 日历系列自动转入规则

勾选“完整备份”后，还会包含待办数据、本地日程、日程转换记录和隐藏记录。

备份不包含 `Generated.inc`、`calendar-cache.json`、`PaperCache`、后台任务状态、程序文件或更新器。这些内容可以重新生成，或者不属于用户配置。

## 加密与版本

本机运行时的三个敏感配置文件继续使用 Windows DPAPI CurrentUser。导出时，程序在内存中读取逻辑配置，再使用备份密码生成的独立密钥加密整个 `.rwbackup` 文件；不会把旧电脑的 DPAPI 密文直接复制到备份。

便携备份使用 PBKDF2-HMAC-SHA256、随机盐、AES-256-CBC 与 HMAC-SHA256 Encrypt-then-MAC。文件被修改、密码错误或认证失败时，不会开始解密或导入。

版本分为两层：

- 加密容器格式版本：`1`
- 用户配置结构版本：`1.0`

容器版本决定文件如何解密；配置版本决定解密后如何迁移字段。后续调整配置结构时，应在 `UpgradeBackupPayload` 中增加从旧配置版本到当前版本的逐级迁移，不应删除 `1.0` 导入支持。

## 导入行为

导入会先显示备份来源版本、待办数量、本地日程数量和自动转入规则数量。用户可以分别选择“配置与凭据”和“完整用户数据”：

- 配置与凭据覆盖对应设置；备份中不存在的敏感配置保持不变。
- 完整用户数据整体替换当前待办和本地日程状态，避免按 ID 合并造成重复或转换关系断裂。
- 未勾选的类别保持不变。

写入前会在当前资源目录建立临时回滚副本。任一文件写入失败时，所有涉及的文件恢复到导入前状态；导入成功后删除临时副本。敏感配置通过当前电脑的 `WriteDpapiJson` 重新加密，因此可以在新电脑当前 Windows 用户下正常读取。

备份密码不会保存在本机，也无法找回。
